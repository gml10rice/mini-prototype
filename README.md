# Uber 3D Pickup – Mini Prototype

A tiny web page that mimics our team's product: a 3D pickup-navigation view that shows a rider
exactly where to walk to meet their driver in confusing places like airports, garages, and campuses.

- **Live page:** https://gml10rice.github.io/mini-prototype/
- **Repo:** https://github.com/gml10rice/mini-prototype

## The button

Click **Show me the way**. It draws a walking route from the rider (blue dot) to the pickup spot,
makes the pickup pin pulse, swaps the headline, and lists step-by-step directions.
Click **Hide route** to reset.

## Run locally

Open `index.html` in any browser. It has no build step and no dependencies.
